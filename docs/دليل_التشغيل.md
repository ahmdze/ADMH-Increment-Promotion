# دليل التشغيل — نظام السجل الوظيفي والعلاوات والترفيعات

الإصدار 0.10.0 (المصدر) — يعمل دون إنترنت، وتبادل البيانات عبر USB.

## 1. المتطلبات

- Windows 10/11 (64 بت).
- لا يحتاج تثبيتاً: انسخ مجلد البرنامج إلى قرص محلي.
- **لا تضعه في `Program Files`** إن أردت بيانات محمولة بجانبه.

## 2. أول تشغيل (مركز الدائرة)

1. **التثبيت (المستحسن):** شغّل `AMDH-HR_Setup_0.10.0.exe` واتبع المعالج؛ يُثبّت
   لكل مستخدم في `%LOCALAPPDATA%\Programs\AMDH-HR` بلا صلاحيات مدير.
   أو فكّ ضغط `AMDH-HR_0.10.0.zip` إلى `C:\AMDH\Center`.
2. شغّل `AMDH-HR.exe` (أو `تشغيل.bat` إن وُجد).
3. **كلمة مرور التشفير**: تُطلب مرة عند أول تشغيل؛ اختر كلمة قوية (8 أحرف فأكثر)
   واحفظها. **لا يمكن استعادتها** إن نسيتها.
4. تظهر شاشة **إنشاء مدير المركز**: اختر كلمة مرور قوية واحفظها.
5. من **المؤسسات** أنشئ **مركز الدائرة** (حدّد «هذا مركز الدائرة»)، ثم المؤسسات.
5. لكل مؤسسة: حدّد عدد الحسابات (حتى 5) واختر إنشاء حساب مدير.
6. بعد الحفظ تظهر **بطاقة الدخول**: اطبعها ورقياً وسلّم كل حساب لصاحبه.
   - كلمات المرور لا تُعرض مرة أخرى.
   - البطاقة تُحفظ أيضاً في `data\reports` (احذفها بعد التسليم).

## 2.1 التشفير (SQLCipher)

- القاعدة مشفرة بكلمة مرور تُطلب عند كل تشغيل؛ لا تُخزَّن الكلمة نفسها.
- المفتاح المشتق في `data\db.key.json` (بذرة + بصمة تحقق) — **لا تنسخه منفرداً
  ولا تحذفه**؛ انسخ مجلد `data` كاملاً.
- **النسخ الاحتياطية مشفرة** بنفس المفتاح وتحتاج كلمة المرور نفسها.
- **الخدمة**: `AMDH_HR_DB_PASSPHRASE` في بيئة جهاز الخدمة، أو شغّل الواجهة مرة
  لتفعيل التشفير ثم شغّل الخدمة.
- **نسخة المؤسسة** تصل قاعدة نصية (لأن الحزمة تُصدَّر نصية)؛ عند أول تشغيل لها
  تُطلب كلمة مرور تشفير خاصة بها، فتصبح مشفرة بمفتاحها.
- إذا نسيت كلمة المرور فلا يمكن استعادة البيانات؛ احتفظ بها في مكان آمن.

## 3. تجهيز نسخة مؤسسة

1. المؤسسات ← زر **«نسخة»** بجانب اسم المؤسسة (أو «تجهيز نسخة»).
2. أدخل **كلمة مرور admin للصيانة**.
3. لتصدير نسخة تحمل **بيانات الدخول** فعّل «تصفير كلمات المرور»؛ ستُعرض بطاقة
   جديدة وتُضمَّن في `بيانات_الدخول.txt`. كلمات المرور القديمة لا يمكن استرجاعها.
4. اختر **تضمين البرنامج** (يتطلب تشغيل النسخة التنفيذية) و**ZIP**.
5. الناتج: مجلد/ZIP يحوي `AMDH-HR.exe` + `_internal` + `data` + بيانات الدخول.
   - هذا **ليس ملف EXE واحداً**؛ هو نسخة كاملة داخل مجلد/ZIP.
   - ملف EXE ذاتي الاستخراج لكل مؤسسة بند منفصل (يُنفَّذ عند الطلب).

## 4. في المؤسسة

1. فكّ الضغط إلى `C:\AMDH\H1` (لا تضعه في Program Files).
2. **مستخدم واحد**: شغّل `AMDH-HR.exe` مباشرة.
3. **عدة مستخدمين على الشبكة الداخلية**:
   - على جهاز الخدمة: `تشغيل_الخدمة.bat` (يترك يعمل).
   - على بقية الأجهزة: عدّل `server.txt` ليعنون جهاز الخدمة، ثم `تشغيل_العميل.bat`.
4. سجّل الدخول بحسابك من البطاقة.

## 5. العمل اليومي

| الصفحة | الاستخدام |
|---|---|
| **الموظفون** | إضافة/تعديل موظف، العناوين الوظيفية، التوزيع، Excel، المرفقات، السجل |
| **كتب الشكر** | كتاب جديد ← النمط ← معاينة ← حفظ ← اعتماد؛ طباعة المستفيدين |
| **الأوامر** | أمر ترفيع/علاوة فردي/جماعي ← اعتماد ← مرفقات ← طباعة |
| **الاحتساب** | اختر الموظف والتاريخ ← احتساب ← **تصدير PDF** أو طباعة النتيجة |
| **القواعد** | زر «المصفوفة المعتمدة» مرة واحدة، أو حزمة جديدة ← قواعد ← نشر |
| **التقارير** | 16 تقريراً؛ HTML أو **PDF مباشر** أو **CSV** أو Excel |
| **المرفقات** | تُفتح داخل البرنامج (PDF/صور) وتُطبع مباشرة |
| **المزامنة** | تصدير/استيراد حزم USB |
| **الإعدادات** | الثيم، النسخ الاحتياطي، كلمة المرور |

### ملاحظات مهمة

- لا يمكن إضافة موظف قبل وجود **عنوان وظيفي**.
- الحساب المقيّد يرى **حصته فقط** من الموظفين.
- **اعتماد الأمر يطبّق الدرجة/المرحلة تلقائياً** (تلقائي أو قيم محددة) ويسجّل التغيير
  في السجل الوظيفي والتدقيق.
- **مصفوفة القِدَم**: 6 أشهر لكتب رئيس الجمهورية/رئيس الوزراء، وشهر واحد للوزير/المخوّل
  بسقف 3 أشهر في السنة الميلادية، ويُرحَّل الفائض للاستحقاق التالي.
- عند **تعادل** تاريخي العلاوة والترفيع، اختر من شاشة الاحتساب: الترفيع أولاً أو العلاوة أولاً.
- نتائج الاحتساب **استرشادية**، ولا تُعد قراراً إدارياً.

## 6. دورة USB الشهرية

```text
المؤسسة: المزامنة ← تصدير بيانات للمركز   →  AMDH_<code>_<time>.amdhpkg
المركز:  المزامنة ← استيراد حزمة مؤسسة    →  معاينة ← نسخة احتياطية ← دمج
المركز:  المزامنة ← تصدير حزمة قواعد
المؤسسة: المزامنة ← استيراد حزمة قواعد
المركز:  المزامنة ← تصدير نتائج الاعتماد
المؤسسة: المزامنة ← استيراد نتائج الاعتماد
```

- الحزم تُحفظ في `data\exports`، وتُشفَّر بكلمة مرور **AES-256-GCM**.
- عند التصدير تُطلب كلمة مرور الحزمة وتأكيدها؛ عند الاستيراد تُطلب مرة واحدة.
- الحزم القديمة غير المشفرة تُستورد بكلمة مرور فارغة.
- إعادة استيراد الحزمة نفسها لا تُكرر البيانات.
- عند تعارض رقم وظيفي بهوية مختلفة تظهر **شاشة تعارضات** لاختيار نسخة المركز أو
  نسخة المؤسسة لكل موظف، ويُربط سجل الحزمة بالهوية المركزية.
- الدمج لا يحذف؛ يُحدّث الأحدث ويُضيف الجديد.

## 7. النسخ الاحتياطي والاستعادة

- الإعدادات ← النسخ الاحتياطي ← **نسخة الآن**.
- النسخ في `data\backups`، وهي **مشفرة** بنفس مفتاح القاعدة.
- قبل كل ترحيل مخطط تُنشأ نسخة `pre_migration_v*.db` تلقائياً.
- للاستعادة: أغلق البرنامج، واستبدل `data\amdh_hr.db` بنسخة سليمة، ثم شغّل
  وأدخل **نفس كلمة مرور التشفير**.
- **لا تحذف `data\db.key.json`**؛ بدونه لا تُفتح القاعدة.
- انسخ `data` كاملة (قاعدة + مفتاح + مرفقات) إلى USB دورياً.

## 8. التحديث

1. خذ نسخة احتياطية.
2. استبدل `AMDH-HR.exe` و`_internal` فقط.
3. **أبقِ `data` كما هي**؛ تُرقّى القاعدة تلقائياً عند أول تشغيل.

## 9. استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| شاشة الدخول لا تتصل | شغّل `AMDH-HR.exe` بلا وسائط (مستخدم واحد). |
| اسم المستخدم | كما في البطاقة (مثل `h1-1`)، وليس الاسم العربي. |
| كلمة المرور | حساسة لحالة الأحرف؛ استخدم «إظهار». |
| نسيت كلمة مرور admin | `python tools\reset_password.py --username admin` (من المصدر). |
| الحساب مقفل | الأداة نفسها تفتح القفل. |
| بطاقة مفقودة | المؤسسات ← «فتح آخر بطاقة»، أو تصفير كلمات المرور. |
| ملف مرفق لا يفتح | تأكد من نوعه (PDF/JPG/PNG/TIFF) وحجمه ≤ 20MB. |

```text
  reports/          بطاقات الدخول وصفحات الطباعة
  logs/             السجلات
```
