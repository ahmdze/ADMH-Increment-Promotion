## 2. نطاق الوظائف المنفّذ

1. **المؤسسات والمستخدمون**: إنشاء مؤسسة بعدد حسابات، كلمة مرور مرة واحدة، بطاقة طباعة، تصفير، حذف، تجهيز نسخة ZIP.
2. **الموظفون**: ملف كامل، عنوان وظيفي مرجعي، سجل وظيفي مؤرخ، توزيع على المستخدمين، Excel، وثائق.
3. **كتب الشكر**: خمسة أنماط استهداف، معاينة المستبعدين، أثر بقواعد، اعتماد، طباعة.
4. **الأوامر**: ترفيع/علاوة فردي وجماعي، اعتماد، مرفقات، طباعة.
5. **القواعد**: حزم مؤرخة، أنواع (ترفيع/علاوة/أثر كتاب)، نشر، إصدار جديد.
6. **الاحتساب**: الخدمة + مصفوفة القِدَم المعتمدة + أهلية الترفيع/العلاوة + ترحيل الفائض + طباعة.
7. **التقارير**: 16 تقريراً، HTML وCSV وExcel و**PDF مباشر**، وعارض PDF/صور داخلي.
8. **USB**: تصدير بيانات مؤسسة، استيراد في المركز مع معاينة وحل تعارضات ونسخة احتياطية، حزم قواعد، حزم نتائج اعتماد.
9. **التشغيل**: خدمة محلية + عملاء، وضع مستخدم واحد، ثيمان.
10. **التشفير**: SQLCipher بكلمة مرور للقاعدة، ونسخ احتياطية مشفرة، وحزم `.amdhpkg` مشفرة AES-256-GCM.

## 5. متطلبات قبل التشغيل الإنتاجي

1. اعتماد **مصفوفة القواعد** (المدد/الآثار/الشروط) من الجهة القانونية والإدارية.
2. إدخال العناوين الوظيفية والدرجات والمراحل المعتمدة.
3. تغيير كلمة مرور `admin` الأولى، وحفظها في مكان آمن.
4. تفعيل نسخ احتياطي يومي على USB منفصل.
5. تجربة مؤسسة واحدة (Pilot) لمدة شهر قبل التعميم.
